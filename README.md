# 💧 MWA Raw Water Totalizer Dashboard (โรงกรองน้ำมหาสวัสดิ์ - MS)

ระบบรายงานและตรวจสอบมิเตอร์น้ำดิบประจำวันอัตโนมัติ สำหรับโรงกรองน้ำมหาสวัสดิ์ การประปานครหลวง (MWA)

## 📌 คุณสมบัติของระบบ (Features)
- 📊 **ข้อมูลมิเตอร์ 4 เฟส:**
  - เฟส 1: MS RWS TOTALIZER (LINE A) • ID 4
  - เฟส 2: MS RWS TOTALIZER (LINE B) • ID 7
  - เฟส 3: MS RWS TOTALIZER (LINE C) • ID 42
  - เฟส 4: MS RWS TOTALIZER (LINE D) • ID 44
- 📈 **ประวัติและปริมาณน้ำ 5 วันย้อนหลัง:** ตัดยอด ณ เวลา 24:00 น. ของแต่ละวัน
- 💧 **คำนวณปริมาณน้ำดิบ (ลบ.ม.):** สูตร `(มิเตอร์ปัจจุบัน - วันก่อนหน้า) × 100`
- 📷 **ภาพถ่ายหน้าปัดมิเตอร์สด:** บันทึกภาพมิเตอร์ RW12 (เฟส 1-2) และ RW34 (เฟส 3-4) ทุกๆ 10 นาที ช่วงเวลา 23:30 - 00:20 น.
- 📱 **รองรับทุกหน้าจอ:** เปิดดูได้สะดวกทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์
